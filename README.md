# chrislynde.ca

Minimal personal landing page built with Astro, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The site is configured for Cloudflare Workers static assets via `wrangler.jsonc`.

```bash
npm run deploy
```

Production domain: `chrislynde.ca`
